# AI × Web3 School — 个人学习仓库

> Personal learning journal and proof-of-work for [AI × Web3 School](https://aiweb3.school).

## 简介

这是一个开源学习仓库，记录我在 AI × Web3 School 的学习历程。

- **Handbook**: https://aiweb3.school/zh/handbook/
- **WCB 课程**: https://web3career.build/zh/programs/AI-Web3-School
- **WCB Learning**: https://web3career.build/zh/programs/AI-Web3-School#tab=learning

## 目录结构

```
├── README.md          ← 本文件
├── profile.md         ← 个人简介 & 学习目标
├── learning-plan.md   ← 整体学习计划
├── daily/             ← 每日学习记录 & 打卡草稿
├── tasks/             ← 学习任务拆解
├── experiments/       ← 实验、代码、实践笔记
├── handbook-feedback/ ← Handbook 反馈（错别字、概念不清、建议）
├── hackathon/         ← Hackathon 项目材料
├── submissions/       ← 课程作业提交
└── templates/         ← 模板文件
```

## ⚠️ 隐私提醒

本仓库为 **public（公开）** 仓库。**不要提交以下内容：**
- API Key、私钥、助记词
- 密码、个人 Token
- 未公开的邮箱、电话、社交媒体
- 他人个人数据
- 内部会议链接

## 使用方式

- 学习记录 → `daily/YYYY-MM-DD.md`
- 课程产出 → `submissions/`
- Handbook 反馈 → `handbook-feedback/YYYY-MM-DD-topic.md`
